# 靈犀

手機優先的命理占卜 App，單一 HTML 頁面，不需後端。整體採紙質感設計（淺色米白紙、深色藏青紙、蠟筆月亮星星與手繪圖示），開啟時有「夜空天眼」開場動畫，可加入手機主畫面當 App 使用（`manifest.webmanifest`、`icons/`）。介面採 iOS 風格：大標題、半透明分頁列、分組卡片，支援淺色與深色模式。

分頁依使用情境排列：**今日**（運勢・星座・解夢・全家）、**問事**（求籤・擲筊・塔羅・易卦）、**日曆**（拜拜・擇日・日記）、**命盤**（紫微・流年・合婚）、**開運**（風水・改名・奇門）。今日頁有「快速入口」一鍵直達常用功能。

- **每日運勢**：七天日期切換（可左右滑動），總分、五大面向、幸運色／數字／方位、白天吉時與「現在這個時辰」好不好、宜忌、每日一牌
- **今日行動指南**：趨吉、避凶、開運、化沖／借合、修心五項，可打勾，並引導到塔羅、求籤、奇門、流月
- **塔羅**：78 張牌（1909 年萊德偉特原版牌面，公有領域，見 `img/tarot/README.md`）、十種牌陣（單張、是非、時間之流、愛情、二選一、身心靈、關係、馬蹄鐵、凱爾特十字、年度運勢），自動洗牌（收攏、旋轉混牌、切牌）後 78 張一次攤開（發牌動畫、選中的牌飛入固定在畫面上方的牌位）、逐張翻牌（每張浮出牌名與關鍵字，翻開時金光掃過、大阿爾克那有光暈）、依所問類別（感情、事業…）逐張解讀、是非／二選一／愛情牌陣直接給結論、年度牌陣列出順風與留意月份、牌與牌的對話（數字重複、宮廷牌、四元素與首尾元素關係）、「來龍去脈」整段故事式解讀（每個位置的讀法、前後牌的能量與元素銜接、總結）、解讀段落快速跳轉、牌義圖鑑、分享解讀、抽牌紀錄
- **求籤・擲筊**：筊杯以「平／凸」清楚標示，關聖帝君神龕（燭火與香煙動畫），依廟宇流程「稟告 → 擲筊請示 → 搖籤筒 → 擲筊確認 → 解籤」，可切換關聖帝君（六十甲子籤）或觀世音菩薩（觀音一百籤，籤詩採台灣好廟網版本，吉／平／宜守與逐句白話為本 App 判讀），籤詩仿廟宇紅籤紙直式排版、逐句白話、典故（僅收錄查得到出處的常見版本）、九類解籤、宜忌與應期、分享籤詩，可開嚴謹模式（連三聖筊）；另有獨立擲筊問事與計數
- **紫微斗數**：「看懂你的命盤」白話總覽（一句話看你、命宮主星、五行局、命主、身主與面向對照表）、全白話宮位解讀（術語以小字附註）、名詞小辭典、十二宮命盤、主星亮度、四化、宮干四化飛星（含自化、忌沖）、三方四正、星曜細論、十二宮逐宮詳批、《紫微斗數全書》格局原文（紫府同宮、機月同梁、七殺朝斗、石中隱玉、極向離明、左右同宮、火貪）、流年疊盤
- **八字詳解**：《滴天髓・天干論》日主原文與白話、日主強弱、喜忌、神煞（天乙貴人、文昌、桃花、驛馬、華蓋、將星、祿神、羊刃、紅鸞、天喜、天德、月德、魁罡、空亡）、四柱刑沖合害
- **合婚配對**：生肖六合三合沖刑害破、日干五合、日支夫妻宮、五行喜用互補、年命納音，加上紫微夫妻宮
- **擇日**：依農民曆（協紀辨方）每日宜忌，所辦之事須在「宜」不在「忌」，排除沖當事人生肖的日子，再以黃道、建除、吉神與嫁娶大利月排序，附十二時辰吉凶
- **流年**：十年流年評分、宜忌、犯太歲（值、沖、刑、害、破）與化解、十二流月、八字大運。生肖與犯太歲依公廟慣例以農曆正月初一換年；八字年柱依子平法以立春換年
- **姓名學**：康熙筆畫五格剖象、81 數理詳解、三才、姓名與八字喜用對照、**改名建議**（依姓氏、性別、喜用神自動找五格皆吉的名字，可指定輩分字、換一批、收藏比較），並檢查名字的聲調平仄是否好唸；三才分「成功運」「基礎運」解說，另有用字檢查（常見不雅諧音、筆畫過多、數字字依數值計畫）
- **奇門遁甲**：時家轉盤拆補法，依問事找用神，點宮看詳解，手機羅盤標出用神與最佳方位並提示轉向；「走財位」顯示此時辰與接下來十二個時辰的生門方位，可選時辰加到行事曆提醒（提前 10 分鐘），首頁有「此時辰財位」小卡，附六步做法、簽約談判的擇時擇方（含中繼點法）與安全提醒
- **個人化每日一段話**：依日主喜忌、當日沖合生肖、本月流月、今年太歲與紫微流日四化寫給命主
- **開運穿搭與飲食**：依喜用五行建議當天的衣服顏色、飾品與五色五味飲食
- **梅花易數・小六壬**：依問題文字（邵雍字占）、時間或報數起卦，有起卦動畫，名詞附白話解釋；本卦、互卦、變卦與體用生剋，附《周易》卦辭與白話，以及「完整解讀」（說卦傳取象、繫辭爻位、互卦與變卦對體卦的生剋）；小六壬掐指六神
- **西洋星座**：太陽星座個性，依當天月亮與太陽實際所在星座的相位推算今日與本月運勢；月空時間（現代通行算法：月亮與太陽～冥王星的最後一個主要相位到換星座，未來 7 天）
- **流月流日**：今年重點月份（換工作、投資、桃花、考試、搬家、健康留意）與可點選的流日月曆
- **個人命書（命盤解說報告）**：以占卜師親筆寫給客人的口吻撰寫——開場信、命書摘要、九章正文（個性、天賦與貴人、人生功課、感情家庭、事業財運、健康、每十年的主題、今明兩年、開運指南），每章先說明依據並附「老師的建議」，結語後附專業資料附錄；八字與紫微互相印證；可列印或存 PDF（檔名含姓名）
- **拜拜與節日**：神明聖誕、年節、初一十五（可選初二十六做牙），可依類別或逐項挑選要加到行事曆的節日（未來一年，可選提醒時間）；每個節日有專屬、可打勾的供品清單（時間、香數、依神明／祖先／地基主分開的供品與金紙），附節日注意事項、拜拜步驟與通則
- **周公解夢**：361 個常見夢境，民間說法搭配心理角度，可搜尋或依類別瀏覽；輸入多個元素（如「狗追蛇」）會產生綜合解讀，結合各元素象徵、夢中互動、數量顏色場景等細節
- **居家風水**：手機羅盤（陀螺儀／磁力計即時顯示面向的八方位、八卦、二十四山，並標出對你是吉方還是凶方）、八宅命卦、八方吉凶羅盤、床頭書桌大門擺設與家人共同吉方
- **簡易模式**：只留今日、問事（求籤・擲筊）、全家三個大分頁與大按鈕；各頁第一次使用有小提示；問題可用說的輸入
- **全家一覽**：全家人今日運勢與今年安太歲名單
- **聲音與震動**：儀式音效（筊杯、籤筒、磬聲、洗牌翻牌）與背景音樂為 `audio/` 兩首配樂（〈儀式靜心〉〈琉璃雨〉，可依頁面自動切換、固定一首或輪播；載入失敗時退回 Web Audio 合成氛圍音樂），音效以 Web Audio 即時合成；Android 用 vibrate，iPhone（iOS 18+）以 switch 觸發觸感回饋
- **占卜日記**：求籤、塔羅、擲筊自動記錄，可回顧是否應驗並統計應驗率
- **自訂首頁**：首頁卡片可開關、排序
- **加到主畫面引導**：用瀏覽器開啟時，在分頁列上方提醒加到主畫面（iOS 版箭頭指向 Safari 分享鈕），附圖解步驟；依 iPhone Safari、iPhone 其他瀏覽器、Android Chrome、LINE／Facebook／Google App 內建瀏覽器各給對應做法，Android 支援一鍵安裝；「不用了」後 7 天再提醒，最多 3 次；設定裡也能找到
- **日夜美術**：白天水墨雲山＋金色星軌、夜晚星空山嵐的背景插畫（`img/bg-day.jpg`、`img/bg-night.jpg`），半透明卡片、宋體標題與標語、直排箴言；往下捲時底部分頁列自動收起，切換分頁記住捲動位置，範例資料在標題下常駐提示
- **每日一牌**：開始抽牌 → 洗牌（可略過）→ 五張牌選一張（可重選）→ 翻開 → 牌名、重點、今日可做的事，完整解讀可展開；結果依日期與命主固定，翻開前先存檔；支援減少動態、簡化動效與震動開關
- **版本更新**：偵測到新版時跳出「更新內容」彈窗（版本號、編號列出新功能、立即更新／稍後更新），內容讀自 `changes.json`；更新後首次開啟也會介紹新內容。發布新版時在 `data/changes.json` 最前面加一筆
- **語音朗讀與分享圖卡**：今日運勢、籤詩、塔羅可一鍵朗讀（可調速度），或做成圖片分享到 LINE（宋體排版、籤詩直排仿籤紙，高度依內容在 1:1 到 9:16 之間自動調整）
- **每日提醒**：產生每天重複的行事曆提醒（.ics），iPhone、Android 皆可
- **離線可用**：Service Worker 快取主程式與萬年曆，加到主畫面後沒網路也能開；紫微元件在首頁顯示後才於背景載入
- **外觀**：跟隨系統、淺色、深色可手動切換；有新版本時提示更新
- **文字大小**：左上角「Aa」可切換標準／大／特大／超大（最大 1.45 倍，整個 App 一起放大重排）與粗體文字，方便長輩使用
- **初次使用引導**：沒填過資料時自動出現歡迎說明，帶著依「姓名 → 性別 → 出生日期 → 時辰」四步驟填寫；漏填會標示並提示
- **多人命盤**：可存自己、家人、另一半的生辰並隨時切換；生日可用國曆或農曆（含閏月）輸入；可選「時辰不確定」

## 開發

```bash
python3 divination/build.py      # 由 src.html + css/ + data/ 產生 index.html 與 sw.js（快取版本號依內容自動更新）
```

- `src.html`：頁面骨架與全部程式
- `css/app.css`：樣式
- `src.html` 內依序為：干支與命盤資料、今日、紫微、流年、姓名、奇門、塔羅、求籤擲筊、導覽與事件
- `data/tarot.js`：塔羅牌義與牌陣
- `data/qian.js`：六十甲子籤詩與解籤
- `data/content.js`：81 數理、星曜、十神、五行開運、取名字庫、各頁說明
- `data/kangxi.js`：康熙筆畫表（由 Unicode Unihan `kRSKangXi` 產生）
- `data/tones.js`：國語聲調表（由 Unihan `kMandarin` 產生），用於名字音律

曆法與紫微排盤使用 [lunar-javascript](https://github.com/6tail/lunar-javascript) 、[iztro](https://github.com/SylarLong/iztro)，月空星曆使用 [astronomy-engine](https://github.com/cosinekitty/astronomy)，已放在 `vendor/`（MIT 授權，附授權檔），jsDelivr 只作為備援。資料只存在使用者自己的瀏覽器。

推到 `main` 後，GitHub Actions 會把本資料夾部署到 GitHub Pages 的 `/divination/`。
