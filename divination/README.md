# 靈犀

手機優先的命理占卜 App，單一 HTML 頁面，不需後端。整體採紙質感設計（淺色米白紙、深色藏青紙、蠟筆月亮星星與手繪圖示），開啟時有紙本墨線的「天眼」開場動畫，可加入手機主畫面當 App 使用（`manifest.webmanifest`、`icons/`）。介面採 iOS 風格：大標題、半透明分頁列、分組卡片，支援淺色與深色模式。

- **每日運勢**：七天日期切換（可左右滑動），總分、五大面向、幸運色／數字／方位、白天吉時與「現在這個時辰」好不好、宜忌、每日一牌
- **今日行動指南**：趨吉、避凶、開運、化沖／借合、修心五項，可打勾，並引導到塔羅、求籤、奇門、流月
- **塔羅**：78 張牌（1909 年萊德偉特原版牌面，公有領域，見 `img/tarot/README.md`）、十種牌陣（單張、是非、時間之流、愛情、二選一、身心靈、關係、馬蹄鐵、凱爾特十字、年度運勢），洗牌與選牌動畫、3D 翻牌、依所問類別（感情、事業…）逐張解讀、是非／二選一／愛情牌陣直接給結論、年度牌陣列出順風與留意月份、牌與牌的對話（數字重複、宮廷牌、四元素與首尾元素關係）、「來龍去脈」整段故事式解讀（每個位置的讀法、前後牌的能量與元素銜接、總結）、牌義圖鑑、分享解讀、抽牌紀錄
- **求籤・擲筊**：筊杯以「平／凸」清楚標示，關聖帝君神龕（燭火與香煙動畫），依廟宇流程「稟告 → 擲筊請示 → 搖籤筒 → 擲筊確認 → 解籤」，六十甲子籤詩（仿廟宇紅籤紙直式排版）、逐句白話、典故（僅收錄查得到出處的常見版本）、九類解籤、宜忌與應期、分享籤詩，可開嚴謹模式（連三聖筊）；另有獨立擲筊問事與計數
- **紫微斗數**：十二宮命盤、主星亮度、四化、宮干四化飛星（含自化、忌沖）、三方四正、星曜細論、十二宮逐宮詳批、《紫微斗數全書》格局原文（紫府同宮、機月同梁、七殺朝斗、石中隱玉、極向離明、左右同宮、火貪）、流年疊盤
- **八字詳解**：《滴天髓・天干論》日主原文與白話、日主強弱、喜忌、神煞（天乙貴人、文昌、桃花、驛馬、華蓋、將星、祿神、羊刃、紅鸞、天喜、天德、月德、魁罡、空亡）、四柱刑沖合害
- **合婚配對**：生肖六合三合沖刑害破、日干五合、日支夫妻宮、五行喜用互補、年命納音，加上紫微夫妻宮
- **擇日**：依農民曆（協紀辨方）每日宜忌，所辦之事須在「宜」不在「忌」，排除沖當事人生肖的日子，再以黃道、建除、吉神與嫁娶大利月排序，附十二時辰吉凶
- **流年**：十年流年評分、宜忌、犯太歲（值、沖、刑、害、破）與化解、十二流月、八字大運。生肖與犯太歲依公廟慣例以農曆正月初一換年；八字年柱依子平法以立春換年
- **姓名學**：康熙筆畫五格剖象、81 數理詳解、三才、姓名與八字喜用對照、**改名建議**（依姓氏、性別、喜用神自動找五格皆吉的名字，可指定輩分字、換一批、收藏比較），並檢查名字的聲調平仄是否好唸；三才分「成功運」「基礎運」解說，另有用字檢查（常見不雅諧音、筆畫過多、數字字依數值計畫）
- **奇門遁甲**：時家轉盤拆補法，依問事找用神，點宮看詳解
- **個人化每日一段話**：依日主喜忌、當日沖合生肖、本月流月、今年太歲與紫微流日四化寫給命主
- **開運穿搭與飲食**：依喜用五行建議當天的衣服顏色、飾品與五色五味飲食
- **梅花易數・小六壬**：依問題文字（邵雍字占）、時間或報數起卦，有起卦動畫，名詞附白話解釋；本卦、互卦、變卦與體用生剋，附《周易》卦辭與白話，以及「完整解讀」（說卦傳取象、繫辭爻位、互卦與變卦對體卦的生剋）；小六壬掐指六神
- **西洋星座**：太陽星座個性，依當天月亮與太陽實際所在星座的相位推算今日與本月運勢
- **流月流日**：今年重點月份（換工作、投資、桃花、考試、搬家、健康留意）與可點選的流日月曆
- **命盤解說報告**：八字、紫微、大運流年、姓名、風水與開運建議彙整成一份，可列印或存 PDF
- **拜拜與節日**：神明聖誕、年節、初一十五（可選初二十六做牙），一鍵把未來一年的節日加到行事曆；每個節日有專屬、可打勾的供品清單（時間、香數、依神明／祖先／地基主分開的供品與金紙），附節日注意事項、拜拜步驟與通則
- **周公解夢**：361 個常見夢境，民間說法搭配心理角度，可搜尋或依類別瀏覽；輸入多個元素（如「狗追蛇」）會產生綜合解讀，結合各元素象徵、夢中互動、數量顏色場景等細節
- **居家風水**：八宅命卦、八方吉凶羅盤、床頭書桌大門擺設與家人共同吉方
- **簡易模式**：只留今日、求籤、全家三個大分頁與大按鈕；各頁第一次使用有小提示；問題可用說的輸入
- **全家一覽**：全家人今日運勢與今年安太歲名單
- **占卜日記**：求籤、塔羅、擲筊自動記錄，可回顧是否應驗並統計應驗率
- **自訂首頁**：首頁卡片可開關、排序
- **語音朗讀與分享圖卡**：今日運勢、籤詩、塔羅可一鍵朗讀（可調速度），或做成圖片分享到 LINE（宋體排版、籤詩直排仿籤紙，高度依內容在 1:1 到 9:16 之間自動調整）
- **每日提醒**：產生每天重複的行事曆提醒（.ics），iPhone、Android 皆可
- **離線可用**：Service Worker 快取主程式與萬年曆，加到主畫面後沒網路也能開；紫微元件在首頁顯示後才於背景載入
- **外觀**：跟隨系統、淺色、深色可手動切換；有新版本時提示更新
- **文字大小**：左上角「Aa」可切換標準／大／特大／超大（最大 1.45 倍，整個 App 一起放大重排）與粗體文字，方便長輩使用
- **初次使用引導**：沒填過資料時自動出現歡迎說明，帶著依「姓名 → 性別 → 出生日期 → 時辰」四步驟填寫；漏填會標示並提示
- **多人命盤**：可存自己、家人、另一半的生辰並隨時切換；生日可用國曆或農曆（含閏月）輸入；可選「時辰不確定」

## 開發

```bash
python3 divination/build.py      # 由 src.html + css/ + data/ 產生 index.html 與 sw.js（快取版本號依內容自動更新）
```

- `src.html`：頁面骨架與全部程式
- `css/app.css`：樣式
- `src.html` 內依序為：干支與命盤資料、今日、紫微、流年、姓名、奇門、塔羅、求籤擲筊、導覽與事件
- `data/tarot.js`：塔羅牌義與牌陣
- `data/qian.js`：六十甲子籤詩與解籤
- `data/content.js`：81 數理、星曜、十神、五行開運、取名字庫、各頁說明
- `data/kangxi.js`：康熙筆畫表（由 Unicode Unihan `kRSKangXi` 產生）
- `data/tones.js`：國語聲調表（由 Unihan `kMandarin` 產生），用於名字音律

曆法與紫微排盤使用 [lunar-javascript](https://github.com/6tail/lunar-javascript) 與 [iztro](https://github.com/SylarLong/iztro)，已放在 `vendor/`（MIT 授權，附授權檔），jsDelivr 只作為備援。資料只存在使用者自己的瀏覽器。

推到 `main` 後，GitHub Actions 會把本資料夾部署到 GitHub Pages 的 `/divination/`。
