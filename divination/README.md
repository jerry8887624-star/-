# 靈犀

手機優先的命理占卜 App，單一 HTML 頁面，不需後端。開啟時有「天眼星盤」開場動畫，可加入手機主畫面當 App 使用（`manifest.webmanifest`、`icons/`）。介面採 iOS 風格：大標題、半透明分頁列、分組卡片，支援淺色與深色模式。

- **每日運勢**：七天日期切換（可左右滑動），總分、五大面向、幸運色／數字／方位、白天吉時與「現在這個時辰」好不好、宜忌、每日一牌
- **今日行動指南**：趨吉、避凶、開運、化沖／借合、修心五項，可打勾，並引導到塔羅、求籤、奇門、流月
- **塔羅**：78 張牌（自繪牌面）、六種牌陣（單張、是非、時間之流、愛情、二選一、凱爾特十字），洗牌與選牌動畫、3D 翻牌、依所問類別（感情、事業…）逐張解讀、是非／二選一／愛情牌陣直接給結論、牌義圖鑑、分享解讀、抽牌紀錄
- **求籤・擲筊**：關聖帝君神龕（燭火與香煙動畫），依廟宇流程「稟告 → 擲筊請示 → 搖籤筒 → 擲筊確認 → 解籤」，六十甲子籤詩、九類解籤、宜忌與應期、分享籤詩，可開嚴謹模式（連三聖筊）；另有獨立擲筊問事與計數
- **紫微斗數**：十二宮命盤、主星亮度、四化、三方四正、星曜細論、流年疊盤
- **流年**：十年流年評分、宜忌、犯太歲化解、十二流月、八字大運
- **姓名學**：康熙筆畫五格剖象、81 數理詳解、三才、姓名與八字喜用對照、**改名建議**（依姓氏、性別、喜用神自動找五格皆吉的名字，可指定輩分字、換一批、收藏比較），並檢查名字的聲調平仄是否好唸
- **奇門遁甲**：時家轉盤拆補法，依問事找用神，點宮看詳解
- **多人命盤**：可存自己、家人、另一半的生辰並隨時切換；可選「時辰不確定」

## 開發

```bash
python3 divination/build.py      # 由 src.html + css/ + data/ 產生 index.html
```

- `src.html`：頁面骨架與全部程式
- `css/app.css`：樣式
- `src.html` 內依序為：干支與命盤資料、今日、紫微、流年、姓名、奇門、塔羅、求籤擲筊、導覽與事件
- `data/tarot.js`：塔羅牌義與牌陣
- `data/qian.js`：六十甲子籤詩與解籤
- `data/content.js`：81 數理、星曜、十神、五行開運、取名字庫、各頁說明
- `data/kangxi.js`：康熙筆畫表（由 Unicode Unihan `kRSKangXi` 產生）
- `data/tones.js`：國語聲調表（由 Unihan `kMandarin` 產生），用於名字音律

曆法與紫微排盤使用 [lunar-javascript](https://github.com/6tail/lunar-javascript) 與 [iztro](https://github.com/SylarLong/iztro)，已放在 `vendor/`（MIT 授權，附授權檔），jsDelivr 只作為備援。資料只存在使用者自己的瀏覽器。

推到 `main` 後，GitHub Actions 會把本資料夾部署到 GitHub Pages 的 `/divination/`。
