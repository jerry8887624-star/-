# 先動五分鐘

拖延症啟動器（手機網頁 App，可加到主畫面、可離線）。

- **找出第一步**：寫下在拖延的事，依類型（寫作、讀書、打掃、運動、回訊息、行政、程式、創作）拆成小到不好意思不做的第一步；覺得太難可按「再小一點」，也可以自己寫。
- **小火苗陪你**：2／5／10 分鐘計時、陪伴角色與每分鐘換一句的鼓勵；可暫停、提早停（也算開始）、做完一步就換下一步；計時時保持螢幕不熄滅。
- **完成後**：再一輪、不計時繼續、或今天先到這裡。
- **火苗罐紀錄**：不算連續天數，只累積開始次數與專注分鐘，月曆標出有開始的日子。
- **心法**：拖延研究的白話整理（附出處）。
- **0.2 新增**：火苗進化（火種→小火苗→營火→篝火→火炬→小太陽，不會退化）；開始前／做完後「有多難受」對比；背景聲音（雨聲、柴火、海浪、低沉噪音、白噪音，Web Audio 即時合成）；依時段與事情類型變化的陪伴語；分享圖卡（不放網址）；每週回顧；待辦小清單；每日提醒（產生行事曆 .ics）；同時專注人數（需部署 `worker/`，未設定則不顯示）。

資料只存在手機瀏覽器（localStorage），不上傳。

開發：改 `src.html`、`js/app.js`、`js/v2.js`、`css/app.css`、`data/changes.json` 後執行 `python3 build.py`。
