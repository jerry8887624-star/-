# 動效規格

原則：少量、短促、可中斷；儀式感集中在核心操作，日常導覽保持快速。全部支援 `prefers-reduced-motion` 與 App 內「簡化動效」（兩者走同一個 `reduceMotion()`）。

| 情境 | 時間 | 曲線／做法 |
|---|---|---|
| 按下回饋 | 80–140ms | scale(.97)，放開回彈 |
| 分頁切換 | 180–240ms | 淡入＋上移 8px |
| 子頁／狀態切換 | 150–220ms | 淡入 |
| 說明展開 | 180–220ms | 高度＋淡入 |
| 卡片移動／收攏 | 180–300ms | cubic-bezier(.16,1,.3,1)，最多一次輕微回彈 |
| 翻牌類揭示 | 420–560ms | rotateY，90° 時換面，cubic-bezier(.2,.75,.25,1) |
| 洗牌類儀式 | 650–900ms | 分疊→交錯→收攏，提供「略過」 |
| 日夜切換 | 250–350ms | 背景與顏色同步過渡 |
| 開場動畫 | 4–6s | 分幕：環境浮現→主視覺描線→核心綻放→標題顯現→提示；可輕觸略過；10 秒保險自動收起 |

## 技術要點
- 只動 transform／opacity；避免對大面積濾鏡做持續動畫。
- SVG 元素旋轉縮放：`transform-box:fill-box; transform-origin:center`，或用 SVG `transform` 屬性。**不要用 px 座標當 transform-origin**（iOS Safari 會位移）。
- 多步驟流程：狀態鎖防重複點擊；先存結果再播動畫；中斷後回來直接顯示結果。
- 揭示後的內容分層進場（標題→摘要→行動建議），每層間隔 80–180ms。
- 觸覺回饋：只在開始、選中、完成各一次輕觸；提供開關；不支援時靜默降級。
- 開場動畫要「炫但有質感」：多層次（星點、主視覺、粒子或光暈、標題光掃）、有節奏的分幕，而不是單一元素淡入。
