# 我們的小島：連線版（部署到 Cloudflare）

部署後，這個 Worker 會同時提供**網站**和**連線伺服器**，網址像 `https://our-island.<你的帳號>.workers.dev`。
用這個網址玩，就能兩個人用自己的手機在同一座小島，也能邀請朋友來玩。
GitHub Pages 上的網址（`…github.io/-/nest/`）還是單機版。

## 一次設定（只要點按，不用打指令）

1. 登入 Cloudflare（和「靈犀」、文昌祠同一個帳號）→ 左側 **Workers & Pages** → **Create**。
2. 選 **Workers** 分頁 → **Import a repository**（匯入存放庫）→ 選這個 GitHub 存放庫。
3. 設定：
   - Project name：`our-island`
   - Build command：留空
   - Deploy command：`npx wrangler deploy`
   - 展開 Advanced settings → **Root directory**：`nest/worker`
4. 按 **Deploy**。完成後畫面上會出現 `https://our-island.….workers.dev`，就是連線版的網址。

之後每次合併到 `main`，Cloudflare 會自動重新部署。

## 怎麼玩
1. **島主 A**：用連線版網址打開 → 右上角 🌐 →「建立我們的小島」（會帶著這支手機目前的存檔）→ 拿到 6 碼**情侶碼**（7 天內有效）。
   - 注意：存檔是存在「網址」底下的。單機版（GitHub Pages）的存檔不會自動跑到連線版網址；在連線版網址重新開始也可以。
2. **島主 B**：用自己的手機打開同一個網址 → 🌐 →「我有情侶碼」→ 輸入。B 手機上的存檔會換成這座島的。
3. **朋友**：島主在 🌐 裡按「分享給朋友」，朋友點連結 → 取暱稱、選樣子 →「登島拜訪」。

## 規則
- 一座島：2 位島主＋最多 4 位朋友。
- 島主之間：牽手、抱抱、親親、摸頭要對方按「好呀」才會開始；牽手時對方會被帶著走（對方推搖桿就放開）。
- 朋友可以玩：釣魚、營火、煙火、沙堡、野餐、划船（可以當乘客）、看夕陽、跳舞、拍照、說一句話、在留言簿留言。
- 只有島主能用：牽手抱抱親親、床、菜園、信箱、衣櫃、回憶本與甜蜜值。
- 島主可以：重設訪客連結（舊連結失效）、請某位朋友離開、把島鎖起來、重新產生情侶碼。
- 兩人共用：名字、造型、甜蜜值、回憶本、菜園、沙堡、收藏、時間（白天黑夜）。
- 另一半不在線上時：島上只有你自己（沒有電腦控制的另一半），等另一半上線再一起玩。

## 伺服器存什麼
- 每座小島：兩位島主共用的存檔、遊戲時間、訪客留言簿（最多 100 則）、訪客碼、是否鎖島、兩把島主鑰匙的雜湊（不存鑰匙本身）。
- 情侶碼（用過或過期就刪除）。
- 朋友只傳暱稱與造型編號；暱稱、說的話、留言都會過濾網址、電話、帳號、住址、約見面與不雅字詞（`js/chatfilter.js`）。

## 本機測試
```
cd nest/worker && npx wrangler dev
```
開 http://127.0.0.1:8787/ 。
