# 我們的小島（情侶小窩 3D 遊戲）

兩個人的 3D 小島：一間小木屋、一片沙灘、一座碼頭、一座燈塔。手機網頁 App（可加到主畫面、可離線），資料只存在這支手機。

## 網址
- 連線版：https://our-island.geso1214.workers.dev
- 單機版：https://jerry8887624-star.github.io/-/nest/

## 連線版（兩個人＋朋友）
部署到 Cloudflare 後（步驟見 `worker/README.md`），用連線版網址打開：右上角 🌐「建立我們的小島」→ 把 6 碼情侶碼給另一半輸入；再用「分享給朋友」邀請最多 4 位朋友。島主之間的牽手、抱抱、親親要對方同意；朋友可以玩公共活動、說話、留言。程式：`js/net.js`（手機端）、`worker/island.js`（伺服器）。

## 玩法
- **開場**：輸入自己的名字、選男生／女生、換樣子（開場畫面就看得到自己），可填「在一起的日子」。島上平常只有自己生活；另一半用 🌐 連線上線時才會出現（沒有電腦控制的另一半）。
- **走動**：左下搖桿、點地板走過去、WASD／方向鍵；拖曳轉鏡頭、雙指或滾輪縮放。點地點標籤會自己走過去並開始活動。
- **💕 互動**：自己可以揮手、轉圈圈、跳、跳舞；另一半在線上時還能牽手（被牽的人會跟著走）、抱抱、親親、摸摸頭（要對方同意）。
- **甜蜜值與等級**：做任何活動都會加甜蜜值。等級：曖昧期 → 剛交往 → 熱戀期 → 形影不離 → 穩定交往 → 老夫老妻 → 靈魂伴侶 → 天生一對。Lv2 解鎖配件「小花」、Lv3 煙火會出現愛心形、Lv4 解鎖「愛心光環」。
- **時間**：遊戲裡一小時 = 36 秒，有日出、夕陽、星空；屋外燈串、門廊燈、碼頭燈晚上會亮。

### 其他
- **👗 衣櫃**：13 套衣服（休閒便服、睡衣、情侶裝），「兩個人一起換情侶裝」一鍵換好。
- **📔 回憶本**：自動記下一起做過的事（日期、小島第幾天）；收藏（釣魚圖鑑、貝殼）；「我們」可改名字、在一起的日子與兩個人的造型。
- **📷 拍照**：藏起介面，選姿勢（抱抱、親親、揮手、歡呼、比心）再按快門，照片下方會印上名字與在一起的天數，可分享或下載。
- **🗺️ 地圖**：列出所有地點，點一下就走過去。
- **🎵 音樂**：四首背景音樂（`audio/`：Island Toybox 島嶼玩具盒、Island Drift 小島漂流、Glassy Pads 玻璃晴空、Cozy Puzzle 暖暖拼圖，使用者提供），用原生 `<audio>` 播放（不經離線快取，iPhone 要分段下載）；🎵 可選自動輪播、指定一首或關閉，切到背景會暫停。音效與營火吉他旋律用 Web Audio 即時合成。

## 3D 模型
全部場景都是 3D：
- 屋子、家具、樹、海灘用品、動物等來自 [Polyfork](https://polyfork.dev) 的低多邊形模型（CC BY 4.0，出處清單在 `models/credits.json`，App「關於」可展開）。下載後用 `npx @gltf-transform/cli optimize in.glb out.glb --compress quantize --texture-compress false --simplify false` 壓縮（共 4.7 MB）。
- **角色（`js/char.js`）**：身體是 Polyfork 的 5 個人物（Neighborhood Child、Teen Player、Kite Kid、Student in a Hoodie、Street Skater，都在 `models/chars/`），縮成脖子高 0.86 公尺；原本的頭縮到看不見，換成我們自己做的 Q 版大頭（`js/avatar.js` 產生，髮型、眼睛、嘴巴、腮紅可換）。衣服用頂點顏色換色（上衣、褲子、圖案、膚色各一區），手上的道具藏起來；共 13 套：休閒便服 7、睡衣 3（加睡帽）、情侶裝 3（胸前愛心）。
- **動作**：坐、吃、澆水、種花、跳舞等 16 個是 Quaternius 的 CC0 動作（Polyfork 轉成 JSON，放在 `anims/`）；走路、待機、跑步、大笑是 Mixamo 動作，授權只能從 Polyfork 線上讀取，第一次讀到後離線快取會存一份；完全沒網路時改用 CC0 的備用動作。抱抱、親親、牽手、揮手、拍手、摸頭、害羞沒有現成動作，用程式把手臂骨頭轉到指定方向。
- 雙人鞦韆、碼頭、野餐墊、菜園、燈串、風箏、煙火、海與天空是程式產生的 3D 幾何（`js/world.js`）。
- 材質統一換成卡通明暗（MeshToonMaterial）；同一種模型很多個用 InstancedMesh；動物用 SkeletonUtils 複製＋AnimationMixer 播 Walk／Idle／Run／Swim。
- three.js r170（`vendor/`）。

## 程式結構
- `index.html`、`css/app.css`：介面。
- `js/terrain.js`：小島地形（純數學：岸邊半徑、高度、哪裡能走、碼頭）。海的著色器裡有一份一樣的岸邊公式。
- `js/world.js`：地形網格、海、天空與一天的光線、擺設位置（`SPOTS`）、室內場景（`INSPOTS`）。
- `js/models.js`：模型載入、卡通材質、InstancedMesh、動物。
- `js/char.js`：角色（Polyfork 身體＋Q 版頭、衣服、動作與姿勢）。`js/avatar.js`：Q 版頭（舊版的全身角色也還在這裡）。
- `js/main.js`：遊戲迴圈、操作、所有活動、連線、對話框、拍照、存檔（`localStorage` 的 `nest.save`）。
- `js/audio.js`：音樂與音效。`js/data.js`：魚、貝殼、信、等級。

## 開發
```
python3 build.py      # 產生 sw.js 版本與更新紀錄（data/changes.json → js/changes.js）
python3 -m http.server   # 在專案根目錄，開 http://localhost:8000/nest/
```
測試用：瀏覽器主控台的 `window.__nest`，例如 `__nest.setTod(20)` 改成晚上八點。
