# 我們的小島（情侶小窩 3D 遊戲）

兩個人的 3D 小島：一間小木屋、一片沙灘、一座碼頭、一座燈塔。手機網頁 App（可加到主畫面、可離線），資料只存在這支手機。

## 網址
- 連線版：https://our-island.geso1214.workers.dev
- 單機版：https://jerry8887624-star.github.io/-/nest/

## 連線版（兩個人＋朋友）
部署到 Cloudflare 後（步驟見 `worker/README.md`），用連線版網址打開：右上角 🌐「建立我們的小島」→ 把 6 碼情侶碼給另一半輸入；再用「分享給朋友」邀請最多 4 位朋友。島主之間的牽手、抱抱、親親要對方同意；朋友可以玩公共活動、說話、留言。程式：`js/net.js`（手機端）、`worker/island.js`（伺服器）。

## 玩法
- **開場**：輸入自己的名字、選男生／女生、換樣子（開場畫面就看得到自己），可填「在一起的日子」。島上平常只有自己生活；另一半用 🌐 連線上線時才會出現（沒有電腦控制的另一半）。
- **走動**：左下搖桿、點地板走過去、WASD／方向鍵；拖曳轉鏡頭、雙指或滾輪縮放。點地點標籤會自己走過去並開始活動。
- **💕 互動**：自己可以揮手、轉圈圈、跳、跳舞；另一半在線上時還能牽手（被牽的人會跟著走）、抱抱、親親、摸摸頭（要對方同意）。
- **甜蜜值與等級**：做任何活動都會加甜蜜值。等級：曖昧期 → 剛交往 → 熱戀期 → 形影不離 → 穩定交往 → 老夫老妻 → 靈魂伴侶 → 天生一對。Lv2 解鎖配件「小花」、Lv3 煙火會出現愛心形、Lv4 解鎖「愛心光環」。
- **時間**：遊戲裡一小時 = 36 秒，有日出、夕陽、星空；屋外燈串、門廊燈、碼頭燈晚上會亮。

### 季節、天氣、任務、裝潢
- **四季**（`js/weather.js`）：小島每 7 天換一季（春→夏→秋→冬）。天氣每 6 小時一段，依「第幾天、幾點」算（連線時兩邊一樣）：晴、多雲、下雨（自動撐傘）、下雪（冬天，地上會積雪）、雨後彩虹。春天飄櫻花、夏夜螢火蟲、秋天落葉。冬天有積雪時可以堆雪人（⛄）。
- **環境音**（`js/amb.js`，`audio/amb/`）：海浪、海鷗、鳥叫、蟲鳴、青蛙、營火、風、雨、雨打傘、腳步，依位置、時間、天氣混音。音檔取自開源專案 Moodist（CC0／Pixabay Content License），剪成無縫循環；另有屋內雨打窗、雞舍雞叫、划船槳聲、門廊風鈴。
- **音效**（`audio/sfx/`）：按鈕、金幣、開關門、木地板腳步、甩竿、落水、咬鉤、水花、澆花、挖沙、翻書取自 Kenney Interface／RPG／Impact／Foley Sounds 與 Ninja Adventure（Pixel-boy & AAA），皆為 CC0；拍照快門聲為使用者提供；做飯、煙火取自 Moodist 錄音。冒愛心、完成的叮咚維持 Web Audio 合成音。
- **每日任務**（📋）：每天 3 個（16 種裡挑），完成各 +20 🪙，全部完成再 +30 🪙。
- **小島幣與收藏獎勵**：釣魚、撿貝殼、堆沙堡、做飯、繞島也會賺 🪙；收集圖鑑達成條件送擺設。
- **裝潢**（點 🪙）：28 種擺設（Polyfork 模型），在屋外或小木屋裡走到想放的地方、轉方向、放下；可以收回包包。
- **傳送、跑步、手電筒**：地圖點地點直接傳送；走路每秒 3 公尺，左下角 🏃 切換跑步（每秒 6 公尺）；🔦 手電筒（聚光燈＋光束，天黑時提醒，連線時別人看得到）。
- **新手教學**、**省電模式**（解析度降低、每秒 30 張；畫面太卡會主動建議）：📔 → 關於。

🛏️ 換上睡衣一起睡到隔天早上（也會讓菜園進到下一天）、🛋️ 沙發看電影、🍳 照食譜做飯（用冰箱裡的魚和雞蛋：荷包蛋、鬆餅、蛋包飯、鹽烤魚、魚湯、生魚片、章魚燒…；釣到的魚可以選「帶回家」）再到 🍽️ 餐桌吃、👗 衣櫃換造型。

## 3D 模型
全部場景都是 3D：
- 屋子、家具、樹、海灘用品、動物等來自 [Polyfork](https://polyfork.dev) 的低多邊形模型（CC BY 4.0，出處清單在 `models/credits.json`，App「關於」可展開）。下載後用 `npx @gltf-transform/cli optimize in.glb out.glb --compress quantize --texture-compress false --simplify false` 壓縮（共 4.7 MB）。
- **角色（`js/char.js`）**：身體是 Polyfork 的 5 個人物（Neighborhood Child、Teen Player、Kite Kid、Student in a Hoodie、Street Skater，都在 `models/chars/`），縮成脖子高 0.86 公尺；原本的頭縮到看不見，換成我們自己做的 Q 版大頭（`js/avatar.js` 產生，髮型、眼睛、嘴巴、腮紅可換）。衣服用頂點顏色換色（上衣、褲子、圖案、膚色各一區），手上的道具藏起來；共 13 套：休閒便服 7、睡衣 3（加睡帽）、情侶裝 3（胸前愛心）。
- **動作**：坐、吃、澆水、種花、跳舞等 16 個是 Quaternius 的 CC0 動作（Polyfork 轉成 JSON，放在 `anims/`）；走路、待機、跑步、大笑是 Mixamo 動作，授權只能從 Polyfork 線上讀取，第一次讀到後離線快取會存一份；完全沒網路時改用 CC0 的備用動作。抱抱、親親、牽手、揮手、拍手、摸頭、害羞沒有現成動作，用程式把手臂骨頭轉到指定方向。
- 雙人鞦韆、碼頭、野餐墊、菜園、燈串、風箏、煙火、海與天空是程式產生的 3D 幾何（`js/world.js`）。
- 材質統一換成卡通明暗（MeshToonMaterial）；同一種模型很多個用 InstancedMesh；動物用 SkeletonUtils 複製＋AnimationMixer 播 Walk／Idle／Run／Swim。
- three.js r170（`vendor/`）。

## 程式結構
- `index.html`、`css/app.css`：介面。
- `js/terrain.js`：小島地形（純數學：岸邊半徑、高度、哪裡能走、碼頭）。海的著色器裡有一份一樣的岸邊公式。
- `js/world.js`：地形網格、海、天空與一天的光線、擺設位置（`SPOTS`）、室內場景（`INSPOTS`）。
- `js/models.js`：模型載入、卡通材質、InstancedMesh、動物。
- `js/char.js`：角色（Polyfork 身體＋Q 版頭、衣服、動作與姿勢）。`js/avatar.js`：Q 版頭（舊版的全身角色也還在這裡）。
- `js/main.js`：遊戲迴圈、操作、所有活動、連線、對話框、拍照、存檔（`localStorage` 的 `nest.save`）。
- `js/audio.js`：音樂與音效。`js/data.js`：魚、貝殼、信、等級。

## 開發
```
python3 build.py      # 產生 sw.js 版本與更新紀錄（data/changes.json → js/changes.js）
python3 -m http.server   # 在專案根目錄，開 http://localhost:8000/nest/
```
測試用：瀏覽器主控台的 `window.__nest`，例如 `__nest.setTod(20)` 改成晚上八點。

## 牽掛與成長（0.9.0）

- **📝 冰箱便利貼**：💕 互動 → 便利貼，或屋內冰箱。留言存在共用存檔（`notes`），對方下次打開第一眼看到，冰箱門上也會貼出來。
- **💗 想你**：另一半在線上就飛愛心過去；不在線上就用手機推播通知（🌐 → 手機通知；iPhone 要先加到主畫面）。推播用 Web Push：VAPID 金鑰由伺服器（Registry DO）第一次使用時自己產生並保存，訊息加密在 `worker/push.js`（RFC 8291），不需要另外設定。
- **💌 你不在的時候**：連上小島時，列出對方貼的新便利貼和做過的事（回憶本的紀錄多了時間與是誰做的）。
- **🎁 每日驚喜**：依小島第幾天決定（兩人看到同一個）：迷路的小兔子、小鴨散步、瓶中信、門口包裹、魚群日、流星雨、母雞好心情。
- **🌳 愛情樹**：兩人每天各照顧一次，同一天都來會長得更快；六個階段，開花後會結愛心果。好幾天沒來只會撒嬌，不會枯死。
- **🎉 紀念日**：在一起 30、50、100、200…天和每週年，會有一封信、禮物和一起放煙火。
- **🖼️ 相片牆**：拍照時存一張小縮圖（最新 6 張），掛在小屋電視上面。
- **💗 成長解鎖**：回憶本「我們」分頁列出每一級解鎖什麼；新增 Lv6 愛情樹下的長椅、Lv7 夜空的愛心星座。
- **🐶 回來的擁抱**：隔天以上沒來，狗狗會衝過來撲到身上；「你來小島 N 天了」只會累加，不會因為沒來就歸零。
- **🌷 輪流的痕跡**：幫對方種的花澆水會有額外甜蜜值，並寫進回憶（對方回來會在「你不在的時候」看到）。
- **🧩 一起拼的拼圖**：客廳茶几上，每人每天最多放 3 片，圖案是最新的合照（沒有照片就用小島夕陽）。
- **🗺️ 升級解鎖新地方**：Lv3 海邊小屋（沙灘西邊，坐在門口聽海）、Lv5 花園溫室（菜園西邊，每天摘一束花送給另一半）；還沒解鎖時標籤會顯示 🔒。模型來自 Polyfork（CC BY 4.0）。
- **📖 圖鑑**：回憶本「收藏」多了一起做過的料理、送過的花。

## 字體與介面（0.9.2）

- **字級**：五級固定階層（`--fs-xs` 12px、`--fs-s` 13.5px、`--fs-m` 15px、`--fs-l` 18px、`--fs-xl` 22px），最小 12px；輸入框固定 16px（iPhone 才不會放大畫面）。
- **字型**：標題、按鈕、標籤、名牌用 jf open 粉圓（Google Fonts 的 Huninn，OFL 授權，分片載入）；內文用思源黑體。
- **乾淨畫面**：走路 1.5 秒或 8 秒沒操作，上方資訊和旁邊的按鈕淡出，一碰螢幕就回來；遠的地點標籤小一點、淡一點。
- **介面長在世界裡**：今日任務是手帳（橫線紙＋紙膠帶）、信是航空信紙、回憶本是相簿、冰箱便利貼是軟木板；每顆按鈕按下去會縮一下。
- **介面風格**（`css/themes.css`，回憶本 → 關於 → 🎨 介面風格）：療癒精品（粉圓＋Fredoka 數字，預設）、時尚雜誌（Playfair Display＋思源宋體標題、細黑體、奶油白配玫瑰金、任務 01／02 編號）、現代玻璃（Outfit＋思源黑體、毛玻璃、全大寫英文小標）。對話框標題會加上英文小標（DAILY QUEST、LETTER、MEMORIES…），各風格自己決定要不要顯示；字型只在選到該風格時才下載。
