# 線上參拜文昌帝君

一座可以自由走動的 3D 線上文昌祠（手機網頁 App，可加到主畫面、可離線）。非官方個人教育作品。

## 玩法
- **暱稱**：進廟前可輸入（最多 8 字，與密語同一套過濾，伺服器再檢查一次），顯示在頭上、名單、密語、打氣與動態；「互動」裡可改；空白則顯示「考生 #編號」。
- **選外觀**：男生／女生、換個造型，或自訂髮型、髮色、膚色、服裝（制服、運動服、漢服、學士服…）、眼鏡。
- **走動**：左下角方向搖桿（推越遠走越快）、點地板走過去；電腦可用 WASD／方向鍵。點場景裡的名牌（辦事處、天公爐、文昌帝君、籤筒、祈福牆）也會走過去。
- **自由視角**：手指左右拖曳轉方向、上下拖曳調高低（可以轉到頭頂往下看）；雙指捏合或滑鼠滾輪拉近拉遠。手機直拿、打橫都可以玩。
- **廟的大小**：正殿寬 30 公尺、深 21 公尺（約第一版 5 倍面積），殿內有柱子、燈籠與一排排**拜墊**：點拜墊或走上去就會跪下，按「叩拜」拜三拜，其他人也看得到。
- **參拜七步驟**（下方按鈕會帶你走到對的位置）：
  1. **備供品**：在辦事處挑供品（蔥＝聰明、芹菜＝勤學、菜頭＝好彩頭、包子粽子＝包中…），取單數；也能點「滷蛋、丸子、紅龜粿」看為什麼不拿來拜。領三炷香與金紙。
  2. **拜天公**：在天公爐前面朝廟外自我介紹，拜三拜，插上第一炷香。
  3. **拜文昌**：供品擺上供桌（3D 會出現），跪在主拜墊（有人就換旁邊）選要考的試、日期、心願，許下還願。
  4. **插香**：另外兩炷插在文昌帝君專屬的**文昌爐**（供桌前，不和天公爐共用）。
  5. **過爐**：准考證影本與文具在文昌爐上，手指順時針繞三圈（也可以按「幫我繞」）。
  6. **燒金紙**：到中庭的**金爐**，依序投入天金（敬天公）、壽金（敬文昌帝君）、刈金（答謝眾神）。
  7. **祈福卡**：選顏色、寫一句話，掛上祈福牆。
- **人多也不卡**：殿內 99 個拜墊、天公爐兩排 13 個拜位，由伺服器分配（一位一人）；滿了就在旁邊遙拜，流程不中斷。走路的人可以互相穿過，站著或跪著的人保持距離。插香、過爐都在拜墊上完成，不用擠到文昌爐前。人多時只顯示最近 12 個名牌。
- **靈犀占卜電子牆**：祈福牆旁的發光螢幕，點了在遊戲內（iframe）打開「靈犀」的今日運勢、星座、解夢、求籤、塔羅、易卦、紫微、流年、合婚、擇日、拜拜、改名；打開時暫停廟裡音樂。
- **再參拜一次**：七步完成後可從頭再拜（祈福卡保留），完成時顯示第幾次參拜。
- **📅 今日**（左上角）：
  - **考試倒數**：設定考試與日期，左上角顯示剩幾天；可下載 .ics 加到手機行事曆（考前一天提醒）。只存在這支手機。
  - **每日一籤**：每天每支手機固定一支籤（依日期＋匿名代碼計算），隔天換新。
  - **每日小任務**：叩拜一次、抽今日一籤、幫 3 張祈福卡加持、打氣或做動作；四項完成算一天，累積 1 天解鎖「金色光環」、3 天解鎖「狀元紅花」（配件會同步給其他人看到）。
  - **祈福牆加持**：點牆上別人掛的小卡就能加持（每張一次），卡片顯示加持數；卡片主人在線上會收到通知。
  - **還願紅榜**：祈福牆旁的紅榜，考上後按「我考上了」，暱稱＋考試掛上紅榜（同一支手機同一種考試只登一次）。
  - **分享圖卡**：參拜完成、還願後可分享圖卡；圖上不放網址，分享文字才附連結。
  - **文昌帝君聖誕**：農曆二月初三（日期已預先換算到 2045 年，見 `js/data.js` 的 `FEAST_DATES`）前兩天到當天，殿前掛紅布條與燈籠，完成每日任務可得限定配件「魁星金冠」。本機測試可加 `?fest=1`。
- **擲筊**：3D 筊杯落地，聖筊／笑筊／陰筊。
- **求籤**：按住籤筒（或搖手機）搖出一支籤 → 擲筊確認 → 六十甲子籤詩、白話、逐句白話、典故，可存成圖片。
- **和其他考生互動**（部署到 Cloudflare 後，見 `worker/README.md`）：看到其他真人考生走動與拜拜、名牌顯示是否完成參拜；點對方或從「互動」名單送打氣語、收到可回覆；揮手／拜一拜／比讚／開心跳讓大家看到；祈福牆顯示大家掛的卡；左下角動態顯示誰進廟、誰完成參拜；**密語**：點對方直接打字聊天、可同時和多人密語（40 字內，擋網址、電話、帳號、住址、約見面；可封鎖／解除封鎖、可關閉接收）。沒有伺服器時（例如 GitHub Pages）廟裡是「示意香客」。
- **白天／夜晚**、**音效**：取用「靈犀」的真實錄音（`audio/sfx/`，Freesound CC0，來源見 `make_sfx.py`）：筊杯、搖籤筒、落籤、磬、小鈴、木魚、展開籤詩；載入前或失敗時用 Web Audio 合成。
- **天公爐拜位**：爐前五個拜位一人一位，滿了會請你稍等；示意香客拜完就離開。
- **讀書角專注**：選好時間後進入全螢幕專注畫面（蓋住遊戲，誤觸地板也不會離開座位；按住「回到廟裡」1 秒才解鎖），可選專注聲音、看專注紀錄（今天／本週／累積）與「今天大家一共專注了幾分鐘」。
- **排行榜**：專注時間（伺服器依實際開始到結束的時間核算）與在廟裡的時間（3 分鐘沒動作不計），各有今日／本週／總榜（台灣時間換日、週一換週），用目前暱稱上榜，可在「互動」關閉。
- **加到主畫面教學**：依 iPhone／Android／LINE、FB 內建瀏覽器／電腦給不同步驟；開場畫面、說明、今日面板常駐入口，第二次進廟或第一次參拜完成時提醒（按過隔 7 天、最多 3 次）。
- **專注聲音來源**：`audio/focus/` 的環境聲取自開源專案 [Moodist](https://github.com/remvze/moodist)（MIT；音檔為 CC0 或 Pixabay Content License，可免費用於作品、不需標註，但不可單獨轉售音檔），已剪成單聲道無縫循環。
- **背景音樂**：取用「靈犀」的四首寺院配樂（`audio/`：〈儀式靜心〉〈缽音入定〉〈晨鐘回響〉〈靜夜安神〉）；右上角音符可選曲或自動輪播（白天寺院系、夜晚〈靜夜安神〉）。用原生 `<audio>` 播放，不經 Web Audio。

姓名、生日、住址、准考證號碼都只顯示在自己畫面上，不儲存也不傳送；祈福卡內容只存在這支手機。

## 開發
- 3D 用 three.js（`vendor/`，MIT 授權），場景與人物全部用程式產生，沒有外部模型檔。
- 籤詩資料沿用 `divination/data/qian.js`。
- 改完任何檔案後：在 `data/changes.json` 最前面加一筆更新紀錄（版本號要變大），再執行 `python3 build.py`。玩家的遊戲會自動跳出「有新版本」提示（立即更新／稍後更新），更新後介紹一次。
