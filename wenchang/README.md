# 線上參拜文昌帝君

一座可以自由走動的 3D 線上文昌祠（手機網頁 App，可加到主畫面、可離線）。非官方個人教育作品。

## 玩法
- **選外觀**：男生／女生、換個造型，或自訂髮型、髮色、膚色、服裝（制服、運動服、漢服、學士服…）、眼鏡。
- **走動**：點地板走過去、拖曳轉動視角；電腦可用 WASD／方向鍵。點場景裡的名牌（辦事處、天公爐、文昌帝君、籤筒、祈福牆）也會走過去。
- **參拜六步驟**（下方按鈕會帶你走到對的位置）：
  1. **備供品**：在辦事處挑供品（蔥＝聰明、芹菜＝勤學、菜頭＝好彩頭、包子粽子＝包中…），取單數；也能點「滷蛋、丸子、紅龜粿」看為什麼不拿來拜。領三炷香。
  2. **拜天公**：在天公爐前面朝廟外自我介紹，拜三拜。
  3. **拜文昌**：供品擺上供桌（3D 會出現），選要考的試、日期、心願，許下還願。
  4. **插香**：回天公爐插上三炷香。
  5. **過爐**：手指在圓圈上順時針繞三圈（也可以按「幫我繞」）。
  6. **祈福卡**：選顏色、寫一句話，掛上祈福牆。
- **擲筊**：3D 筊杯落地，聖筊／笑筊／陰筊。
- **求籤**：按住籤筒（或搖手機）搖出一支籤 → 擲筊確認 → 六十甲子籤詩、白話、逐句白話、典故，可存成圖片。
- **和其他考生互動**（部署到 Cloudflare 後，見 `worker/README.md`）：看到其他真人考生走動與拜拜、名牌顯示是否完成參拜；點對方或從「互動」名單送打氣語、收到可回覆；揮手／拜一拜／比讚／開心跳讓大家看到；祈福牆顯示大家掛的卡；左下角動態顯示誰進廟、誰完成參拜；**悄悄話**：邀請對方、對方接受後一對一聊天（40 字內，擋網址、電話、帳號、住址、約見面，可封鎖）。沒有伺服器時（例如 GitHub Pages）廟裡是「示意香客」。
- **白天／夜晚**、**聲音**（Web Audio 即時合成磬聲、筊聲）。

姓名、生日、住址、准考證號碼都只顯示在自己畫面上，不儲存也不傳送；祈福卡內容只存在這支手機。

## 開發
- 3D 用 three.js（`vendor/`，MIT 授權），場景與人物全部用程式產生，沒有外部模型檔。
- 籤詩資料沿用 `divination/data/qian.js`。
- 改完任何檔案後執行 `python3 build.py`（更新 service worker 版本）。
